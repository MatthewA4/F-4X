## 🔥 ENGINE START PROCEDURE

### Engine 1 Start
```
1. Cutoff Switch 1:               ON (block fuel)
2. Starter Switch 1:              ENGAGE (hold 3-5 sec)
3. Observe N2 Spool:              Watch gauge rise to ~50-60%
4. Throttle 1:                    Adjust to ~30% (idle)
5. When N2 stable >65%:           Cutoff OFF (open fuel)
6. Watch N1:                      Rise from 0 to ~28% idle (warm)
7. Generator 1:                   Should illuminate automatically (N2 >60%)
8. Wait for stabilization:        30 seconds minimum
```

### Engine 2 Start  
- Repeat Engine 1 procedure
- Verify both engines at idle (N1 ~28%, N2 ~65%)
- Check electrical buses: AC Main & AC Standby

### Preflight Systems Check
- [ ] Hydraulic Pressure A:     2,800-3,000 psi (Engine 1 pump)
- [ ] Hydraulic Pressure B:     2,800-3,000 psi (Engine 2 pump)
- [ ] Fuel Quantity:             Total & individual tanks
- [ ] Electrical:                 AC main online, Gen 1 & 2 online
- [ ] Pressure Instruments:      All in green range
- [ ] Flight Controls:           FREE & RESPONSIVE
- [ ] Trim:                      Elevator 1.0°, Aileron CENTER, Rudder CENTER

### ⚠️ TRANSONIC BAND (M 0.85-1.05) - SPECIAL PROCEDURES

```
CRITICAL: Static pressure errors cause ADC airspeed fluctuations.  
AFCS altitude-hold integrator automatically reduced 50%.
  
Procedure:
1. Climb to FL 250-300 (clean config)
2. Throttle: FULL MIL or LIGHT AB
3. Autopilot: Engage ALT-HOLD (system compensates)
4. Expected: Slight altitude variations ~100-200 ft (normal)
5. If oscillations >500 ft: Switch to PITCH-HOLD
6. Resume ALT-HOLD after M >1.05 transonic exit

Configuration:
- Flaps: 0° (UP)
- Gear: UP
- Speed Brakes: IN
- Afterburner: Monitor envelope (light AB acceptable if heat OK)
```

## 🚨 STALL & RECOVERY

### Stall Warning Indicators
```
Angle of Attack:               >20° units (flaps down) or >18° (clean)
Rudder Pedal Vibration:        ~10 Hz shaker felt in feet
Audio Warning:                 Loud stall horn sounding
```

### Recovery Procedure
```
1. **Immediate Action:**
   - Push stick forward (reduce pitch)
   - Reduce AOA below 15°
   - Throttles: ADVANCE to full power

2. **Maintain Control:**
   - Use smooth aileron inputs (avoid aggressive roll)
   - Rudder: Coordinate; avoid cross-control
   - Altitude: Descend if necessary (exchange altitude for airspeed)

3. **Resume Normal Flight:**
   - When airspeed >200 knots CAS and AOA <15°
   - Resume climb or level-off as needed
```

### Post-Stall Recovery
- [ ] Airspeed: Confirm >150 knots CAS (safe)
- [ ] Altitude: Verify sufficient AGL for safe recovery
- [ ] Heading: Verify not in undesired turn
- [ ] Flight Controls: Check responsive to input

## 🆘 EMERGENCY PROCEDURES

### Dual Engine Failure (Total Power Loss)
```
AUTOMATIC ACTIONS:
- RAM Air Turbine (RAT) deploys immediately
- Hydraulic pressure: ~2,000 psi (emergency source)
- Flight controls: Remain responsive
- Electrical: Battery backup available ~30 min

PILOT IMMEDIATE ACTIONS:
1. Declare emergency to ATC
2. Set throttles to IDLE (confirm engines stopped)
3. Pitch: SET nose down 3-5° descent glide
4. Airspeed: Maintain 180+ knots (critical for RAT)
5. Altitude: Calculate descent distance to nearest airfield

DESCENT CALCULATION:
  Altitude / 1,000 ft = approx nm glide distance (4:1 ratio)
  Example: 10,000 ft ÷ 1,000 = 10 nm glide range

APPROACH PLAN:
- Find nearest suitable runway
- Descend at 500 ft/min rate
- Avoid steep turns (RAT pressure needs airspeed)
- Make straight-in approach (no go-around possible)
- Land straight ahead; do not attempt climb-out
```

### Hydraulic System Failure (Single Circuit)
```
If Hydraulic Pressure A <500 psi:
- FCS operates on System B only
- Cross-feed solenoid engages (if available)
- Control authority reduced but maintained
- Can land safely with reduced control inputs

If Both A & B Pressure Lost:
- Emergency: RAT auto-deploys
- Declare emergency
- Land immediately at nearest airfield
```

### Electrical System Failure
```
If Generators Lost (battery only):
- AC bus de-energized (~30 min battery life)
- DC essential bus powered by battery backup
- Instruments: Powered-essential items only
- Radios: UHF/VHF may be limited
- Navigation: Basic compass/clock navigation required
- Land immediately before battery depleted
```

### Engine Failure (Single Asymmetric)
```
Engine 1 Flameout:
1. Throttle 1: Cutoff (secure engine)
2. Airspeed: Maintain >180 knots
3. Heading: Compensate for yaw with rudder
4. Altitude: Continue climb on Engine 2 only (~8,000 ft/min climb possible)
5. Landing: Approach on Engine 2 power; monitor landing distance

Engine Performance (Single):
- Max altitude on one engine: ~35,000 ft
- Max speed single engine: M 1.2
- Climb rate: ~8,000-12,000 ft/min (altitude dependent)
- Endurance: Limited; plan immediate landing
```

### Fire/Overheat
```
Engine Overheat Warning (EGT >950°C):
1. Power: Reduce throttle 10-20%
2. Cooling: Increase airspeed (descent if necessary)
3. Monitor: Watch EGT back into green range
4. If persists: Consider engine shutdown (CUTOFF)

Fuselage Fire Warning:
1. Declare emergency immediately
2. Land at nearest airfield (do not delay)
3. Fire suppression: Check fire bottles armed
4. Maintain controlled descent; do not attempt climb
```

## ✅ SHUTDOWN PROCEDURE

### After Landing (Parking)
- [ ] Parking Brake:           SET
- [ ] Throttles:               IDLE
- [ ] Speed Brakes:            IN (retracted)
- [ ] Flaps:                   0° (UP)
- [ ] Landing Lights:          OFF
- [ ] Anti-Collision Lights:   OFF
- [ ] Trim:                    NEUTRAL

### Engine Shutdown
```
Engine 1:
1. Throttle 1:               MOVE to OFF/CUTOFF
2. Monitor N2 wind-down:     Should drop to 0% within 30 sec
3. RPM Check:                N1 = 0%, N2 = 0% (both at zero)

Engine 2:  
- Repeat Engine 1 procedure
- Both engines must show 0% N1/N2 for complete shutdown
```

### System Shutdown  
- [ ] Generators 1 & 2:       OFF (or automatic once engines stopped)
- [ ] Electrical:             Verify no essential buses powered
- [ ] Master Battery:         OFF (last switch)
- [ ] Flight Controls:        Verify no trim remain (neutral)
- [ ] Fuel Transfer:          OFF (manual switches as applicable)

### Parking Final Checklist
- [ ] Exterior: Canopy OPEN (cool cockpit)
- [ ] Gear: DOWN & LOCKED (verify manually)
- [ ] All Systems: Powered OFF
- [ ] Ejection Seat: SAFE PIN INSTALLED (before crew exit)
- [ ] Emergency Equipment: Checked & stowed
- [ ] Form 781: Discrepancies noted for maintenance
